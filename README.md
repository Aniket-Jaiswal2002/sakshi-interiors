# Sakshi Interiors — Business Website

A fully responsive, SEO-optimised business website built for a real interior design and renovation company based in Gurugram, India. Live at [sakshiinteriors.in](https://www.sakshiinteriors.in).

## About the Project

This is a real client project — a professional website for Sakshi Interiors, a renovation company with 30+ years of experience serving Gurugram and Delhi NCR. Built with pure HTML and CSS, no frameworks.

## Features

- Fully responsive — works on mobile, tablet, and desktop
- SEO optimised with meta tags, Open Graph, Twitter cards, and canonical URLs
- Google Schema markup (`LocalBusiness`) for Google Search visibility
- WhatsApp and Facebook link preview support
- Custom Google Fonts (Cormorant Garamond + DM Sans)
- Smooth scroll and minimal JavaScript
- Deployed with a custom domain via GitHub Pages

## Services Showcased

- Tile & Stone Installation
- False Ceiling & POP Work
- Interior & Exterior Painting
- Electrical Solutions
- Custom Woodwork
- Complete Renovation

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript
- GitHub Pages (hosting)
- Custom domain — sakshiinteriors.in
